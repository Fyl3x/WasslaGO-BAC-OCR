What is extracted

  • رقم التسجيل — registration number
  • بكالوريا دورة — session year
  • شعبة — branch
  • السيد (ة) — full name
  • المزداد (ة) في / بـ — birth date & place
  • المؤسسة — institution name & code
  • المادة / النقطة / المعامل / المجموع — grades table
  • المجموع العام & المعدل العام
  • حرر بالجزائر في — issue place & date
  • الرقم السري — secret code
  • الكود الطويل (USEPWD_BC) — serial code
